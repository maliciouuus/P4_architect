# DataShare — prototype de transfert de fichiers

Projet réalisé dans le cadre de la mission **« Pilotez le développement d'une solution informatique »**.

## Contexte

**DataShare** est une plateforme web de **transfert sécurisé de fichiers** : dépôt de fichiers, génération de liens de téléchargement, comptes utilisateurs et historique. Ce dépôt contiendra le **MVP** (produit minimum viable) prévu pour une démonstration.

## Stack prévue (à confirmer au fil du projet)

- **Back-end** : Django + API REST
- **Front-end** : Vue.js
- **Base de données** : PostgreSQL
- **Stockage des fichiers** : disque local pour le prototype

## État actuel

Mise en place initiale du dépôt : documentation minimale et règles d’ignorance Git. Le code applicatif viendra dans les prochains commits.

## Prochaines étapes

- Définir l’architecture et le modèle de données
- Initialiser le back-end et le front-end
